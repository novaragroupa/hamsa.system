# نظام إدارة همسة للسياحة

نموذج تفاعلي (Prototype) لنظام إدارة شركة همسة للسياحة — تسجيل دخول بأدوار متعددة، ولوحات تحكم منفصلة لكل قسم (المدير، HR، العلاقات العامة إن دور/أوت دور، الاستقبال، الحسابات، الكول سنتر، التسكين، حجوزات النظام).

## الملفات

```
homsa-system/
├── index.html          # الواجهة كاملة (تعمل مباشرة في المتصفح، بدون تنصيب)
├── backend/
│   └── Code.gs          # سكريبت Google Apps Script لربط النظام بجوجل شيت
└── README.md
```

## طريقة التشغيل السريع

افتح `index.html` في أي متصفح مباشرة، أو فعّل GitHub Pages للريبو (Settings → Pages → اختر branch: main، Folder: /root) وهيديك رابط تقدر تفتح منه النظام من أي مكان.

**حسابات تجريبية:**

| المستخدم | كلمة المرور | الدور |
|---|---|---|
| admin | admin123 | مدير النظام |
| hr | hr123 | HR |
| pr_out | pr123 | علاقات عامة - أوت دور |
| pr_in | prin123 | علاقات عامة - إن دور |
| reception | rec123 | استقبال |
| accounting | acc123 | حسابات |
| callcenter | cc123 | كول سنتر |
| accommodation | acco123 | تسكين |
| system | sys123 | حجوزات النظام |

> ⚠️ دول حسابات تجريبية ثابتة في الكود لغرض العرض فقط — قبل الاستخدام الفعلي لازم تتغير آلية الدخول لتكون آمنة (مثلاً عبر جدول "users" في جوجل شيت + Apps Script، بدل الحسابات المكتوبة في الملف).

## الحالة الحالية للبيانات

النظام حاليًا بيخزن البيانات باستخدام تخزين مؤقت داخلي (يفضل موجود طالما الصفحة نفس الرابط)، وده كافي لتجربة الشكل والفكرة، لكنه **مش قاعدة بيانات حقيقية مشتركة بين الأجهزة**.

## الربط بجوجل شيت (الخطوة الجاية)

الملف `backend/Code.gs` فيه كل التعليمات خطوة بخطوة لعمل:
1. جوجل شيت بتبويبات لكل قسم (employees, companies, visits...).
2. سكريبت Apps Script يشتغل كـ API بسيط (قراءة/إضافة/تعديل/حذف).
3. رابط Web App بعد الـ Deploy، يتحط في `index.html` بدل التخزين المؤقت.

هي الخطوة اللي لسه محتاجة نعملها عشان يبقى النظام فعلي بالكامل.

## ملاحظة مهمة

ده لسه نموذج أولي لتجربة الفكرة والتصميم قبل بناء نسخة إنتاجية حقيقية (بقاعدة بيانات وأمان مناسب لبيانات الموظفين والمرتبات وبيانات العملاء).
